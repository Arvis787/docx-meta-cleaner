# Docx Meta Cleaner

Небольшая Windows-программа для очистки метаданных в документах Word OpenXML.

[Скачать EXE](downloads/DocxMetaCleaner-v1.0.0.exe) · [Скачать ZIP](downloads/DocxMetaCleaner-v1.0.0.zip) · [Страница скачивания](https://arvis787.github.io/docx-meta-cleaner/)

## Что делает программа

- очищает один выбранный Word-файл;
- очищает все поддерживаемые Word-файлы в папке;
- при необходимости проходит по подпапкам;
- может создавать резервные копии `.bak` перед изменением файлов;
- запоминает последнюю выбранную папку;
- запускается как обычное Windows-приложение без консольного окна.

Поддерживаются форматы `.docx`, `.docm`, `.dotx`, `.dotm`.

Старые `.doc` не поддерживаются, потому что это бинарный формат Word, а не OpenXML/ZIP.

## Скачать и запустить

1. Откройте страницу скачивания: `https://arvis787.github.io/docx-meta-cleaner/`.
2. Нажмите **Скачать для Windows**.
3. Запустите `DocxMetaCleaner-v1.0.0.exe`.
4. Выберите один файл или папку с документами.
5. Оставьте включенными резервные копии, если хотите сохранить исходные файлы рядом с обработанными.
6. Нажмите **Очистить метаданные**.

Программа не требует установки. Если Windows SmartScreen покажет предупреждение, это связано с тем, что файл не подписан платным код-сертификатом.

## Что именно очищается

Программа удаляет из OpenXML-пакета Word:

- содержимое `docProps/*`, включая `core.xml`, `app.xml`, `custom.xml` и миниатюры;
- связи на `docProps/*` из `_rels/.rels`;
- записи `/docProps/*` из `[Content_Types].xml`;
- ZIP-комментарии, extra-поля и исходные временные метки ZIP-записей.

Содержимое документа, текст, изображения, стили и макросы `.docm` не удаляются.

## Где хранятся настройки

Путь к последней выбранной папке и параметры галочек сохраняются здесь:

```text
%APPDATA%\Docx Meta Cleaner\settings.json
```

Если удалить этот файл, программа снова начнет с настроек по умолчанию.
