# Docx Meta Cleaner

Windows-программа для очистки метаданных документов Word, презентаций PowerPoint и таблиц Excel. Текущая версия: **1.2.0**.

[Скачать EXE](https://raw.githubusercontent.com/Arvis787/docx-meta-cleaner/main/downloads/DocxMetaCleaner-v1.2.0.exe) · [Скачать ZIP](https://raw.githubusercontent.com/Arvis787/docx-meta-cleaner/main/downloads/DocxMetaCleaner-v1.2.0.zip) · [Страница скачивания](https://arvis787.github.io/docx-meta-cleaner/)

## Что делает программа

- очищает один выбранный файл Word, PowerPoint или Excel;
- очищает все поддерживаемые файлы в папке, в том числе смешанные наборы;
- при необходимости проходит по подпапкам;
- может создавать резервные копии `.bak` перед изменением файлов;
- восстанавливает выбранный файл или папку после перезапуска, включая рабочий стол;
- позволяет выбрать рабочий стол отдельной кнопкой с учётом переноса папки в OneDrive;
- запускается как обычное Windows-приложение без консольного окна.

| Приложение | Поддерживаемые форматы |
| --- | --- |
| Word | `.docx`, `.docm`, `.dotx`, `.dotm` |
| PowerPoint | `.pptx`, `.pptm`, `.potx`, `.potm`, `.ppsx`, `.ppsm` |
| Excel | `.xlsx`, `.xlsm`, `.xltx`, `.xltm` |

Старые бинарные `.doc`, `.ppt`, `.xls`, а также `.xlsb` не поддерживаются. Сохраните их в соответствующем современном формате через Office. Файлы с паролем необходимо сначала расшифровать в Office.

## Скачать и запустить

1. Откройте страницу скачивания: `https://arvis787.github.io/docx-meta-cleaner/`.
2. Нажмите **Скачать для Windows**.
3. Запустите `DocxMetaCleaner-v1.2.0.exe`.
4. Выберите один файл, папку с файлами Office или нажмите **Рабочий стол**.
5. Оставьте включенными резервные копии, если хотите сохранить исходные файлы рядом с обработанными.
6. Нажмите **Очистить метаданные**.

Программа не требует установки Microsoft Office или Python и работает локально. EXE не подписан цифровой подписью; Windows может показать предупреждение SmartScreen.

## Что именно очищается

Программа удаляет из пакетов Word, PowerPoint и Excel:

- содержимое `docProps/*`, включая `core.xml`, `app.xml`, `custom.xml` и миниатюры;
- связи на удалённые свойства из файлов `.rels`;
- записи `/docProps/*` из `[Content_Types].xml`;
- ZIP-комментарии, extra-поля и исходные временные метки ZIP-записей.

Текст, изображения, стили, слайды, заметки докладчика, листы, формулы и макросы сохраняются. Очистка касается свойств файла (автор, даты, название, пользовательские свойства, миниатюры) и служебных ZIP-данных. Комментарии, исправления, авторы комментариев и сведения внутри текста или вложений не удаляются.

Обрабатываемые файлы заменяются на месте. Резервные копии сохраняются рядом: `имя.xlsx.bak`, затем `.bak.1`, `.bak.2` и т. д. Чтобы восстановить исходник, скопируйте резервную копию и уберите суффикс `.bak` (или `.bak.N`).

Свойства файла общие для форматов Office: [документация Microsoft об Open XML](https://learn.microsoft.com/en-us/office/open-xml/about-the-open-xml-sdk).

## Где хранятся настройки

Выбранный файл или папка, последняя папка диалога и параметры галочек сохраняются здесь:

```text
%APPDATA%\Docx Meta Cleaner\settings.json
```

Если удалить этот файл, программа снова начнет с настроек по умолчанию.

## Запуск из исходников и сборка

Для запуска достаточно Python 3.13 с Tkinter, сторонние библиотеки приложению не нужны:

```powershell
python DocxMetaCleaner.py
```

Для сборки и тестов:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -m PyInstaller --noconfirm --clean --onefile --windowed --name DocxMetaCleaner-v1.2.0 --icon assets/app.png --add-data "assets/app.png;assets" DocxMetaCleaner.py
```

Готовый EXE находится в `dist/`. Старые файлы версии 1.0.0 оставлены в `downloads/`.
